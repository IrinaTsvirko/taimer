☁️ Синхронизация между устройствами (телефон ↔ компьютер)
Записи всегда сохраняются в браузере — они не пропадут при перезагрузке страницы. Чтобы они были видны ещё и на другом устройстве, подключите бесплатное облако: Google Apps Script + Google Таблица (файл apps-script/Code.gs из репозитория).
  1. Откройте script.google.com → новый проект.
  2. Вставьте код из Code.gs, сохраните и запустите функцию setup (разрешите доступ). В логе появится ссылка на таблицу и ключ.
  3. Развернуть → Новое развёртывание → тип «Веб-приложение»: запуск от имени «Я», доступ «Все». Скопируйте URL, заканчивающийся на /exec.
  4. Вставьте URL и ключ ниже на каждом устройстве и нажмите «Сохранить» → «Проверить связь».
Альтернатива без настройки: откройте файл apps-script/app.html через «Развернуть → Веб-приложение» — тогда облако подключено сразу, без URL и ключа.
